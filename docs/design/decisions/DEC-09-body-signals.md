**Summary.** Each body signal carries one main piece of information: core colour is temperature, core intensity is dirt, size is mass, and cohesion is read from the core rhythm and the jelly softness.

## Question
What do dirt and the core glow tell the player?

## Decision

| Signal | Information |
|---|---|
| Core colour | Temperature (four colours, sheet 1) |
| Core intensity | Dirt only |
| Size of the slime | Mass |
| Core rhythm (slower as it drops) and jelly softness | Cohesion |

The proposed "core flash = event" (digestion done, taste) was NOT retained.

## Proposal as submitted (for the record)
Core colour = temperature, doubled by shape and effects for colour-blind players; core intensity dimmed by the coating; core flash = event; cohesion = body shape only; hunger = size only (dropping "dull" from the GDD); one coating at a time among four types.
