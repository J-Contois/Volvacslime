**Summary.** Proposal: nothing is displayed permanently during play; the reticle appears only in aim mode, and the archive and recipe notebook live in the pause menu.

## Question
Which interface elements are acceptable, given the GDD belly wheel, reticle gauge, notebook and archive against "no menu" and "no gauge" on the sheets?

## Decision
Not decided.

## Proposal

| Element | Proposal |
|---|---|
| Reticle and trajectory | Only in aim mode, because precision requires it |
| Choosing a belly object | No wheel by default: scroll through objects, the chosen one is highlighted inside the body; a wheel only if a playtest shows a problem above N objects (N TODO) |
| Cohesion | Read on the body (sheet 3), no gauge; reticle ring only as a fallback after playtest |
| Fragment archive and recipe notebook | Off-game screens in the pause menu, presented as the slime's memory |
| Accessibility | Optional minimal display (state and temperature as text or icon); shape redundancy for core colours (N10) |
